# Real-Estate-Analysis-Project | Power BI
Real Estate Sales & Performance Dashboard

📌 Project Overview

The Real Estate Sales & Performance Dashboard is an interactive data analytics project developed using Microsoft Power BI to analyze real estate sales performance, revenue generation, target achievement, and property distribution across different projects.

The dashboard transforms raw real estate data into meaningful visual insights, helping users understand project performance, compare actual sales against targets, identify revenue contributions, and explore property status and property types.

Interactive slicers allow users to filter the dashboard by Project Name, Property Status, and Property Type, making it easier to explore the data and compare performance across different categories.

🎯 Project Objectives

Analyze overall real estate sales and revenue performance.

Monitor sales target achievement.

Compare actual sales with targets across projects.

Understand sales distribution by property type.

Analyze property status distribution.

Identify projects contributing to sales and revenue.

Present key performance indicators through an interactive dashboard.

🧹 Data Cleaning and Preparation

Data preparation was performed using Power Query Editor in Power BI to improve data consistency and prepare the dataset for analysis.

The main data-cleaning operations included:

Filtered Rows: Applied row filters to prepare the relevant data for analysis.

Trimmed Text: Removed unnecessary leading and trailing spaces from text values.

Cleaned Text: Cleaned text data to improve consistency.

Removed Duplicates: Removed duplicate records according to the applied selection.

Replaced Values: Replaced missing or blank values with Unknown where applicable.

Renamed Columns: Improved column names for readability and easier analysis.

These steps helped prepare the data for dashboard development and reporting.

📈 Key Performance Indicators (KPIs)

The dashboard includes the following KPI cards:

Total Properties: Displays the total property count represented by the dashboard.

Total Sales: Summarizes sales performance.

Total Revenue: Displays the revenue generated.

Total Target: Shows the overall sales target.

Target Achievement: Displays target achievement as a percentage to evaluate progress against the target.

📉 Dashboard Visualizations

The dashboard contains the following visualizations:

1. Sales Distribution by Property Type

A pie chart used to compare sales distribution across property types, such as New Property and Sales categories represented in the dataset.

2. Property Status Distribution

A doughnut chart showing how properties are distributed across different status categories.

3. Sales Contribution by Project

A treemap illustrating the relative contribution of individual projects to sales.

4. Actual Sales vs Target by Project

A stacked column chart used to compare actual sales and target values across projects.

5. Revenue by Project

A bar chart comparing revenue generated by different projects.

6. Project Performance Summary

A table presenting project-level performance details for a more direct comparison of projects.
